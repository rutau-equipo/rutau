# Plan ficticio de pruebas

**No es un plan oficial de la UNAH.** Este paquete sirve para verificar que el motor académico y la app funcionen antes de cargar planes reales.

Para agregar un plan oficial: crear otro paquete con `plan.json`, registrar la URL oficial en `source.url`, documentar la versión correcta y abrir un Pull Request. No reemplazar un plan histórico por una actualización diferente.
